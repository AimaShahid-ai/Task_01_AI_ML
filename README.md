## Task 01 – Python Programming, Data Analysis & Visualization

# Project Objective

The objective of this project is to analyze student performance using Python, data analysis, statistical analysis, and data visualization. The project focuses on cleaning the dataset, exploring important patterns and relationships, creating meaningful visualizations, and generating insights from the analysis.

# Dataset Description

The Student Performance Dataset contains information about students' academic performance, including attendance, internal test scores, assignment scores, daily study hours, and final exam marks.

# Dataset Source

The dataset was obtained from Kaggle.

- Data Visualization

1. Dataset Loading

9. Final Conclusion

# Major Findings

- Attendance has the strongest positive relationship with Final Exam Marks.
- Internal test scores also show strong positive relationships with Final Exam Marks.
- Daily Study Hours show a weaker positive relationship with final exam performance.
- Most students' final exam marks are concentrated around the middle score range.
- Overall, attendance and internal assessment performance are important factors associated with final exam performance.
